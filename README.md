# 🛴 API Тесты для Яндекс.Самокат

## 📋 О проекте
Полный набор автотестов для REST API сервиса Яндекс.Самокат. Тестируются сценарии работы с курьерами и заказами.

## 🎯 Что тестируется

### 📦 Тесты заказов (Order Tests)
✅ Создание заказа с разными параметрами цвета  
✅ Создание заказа без указания цвета  
✅ Получение заказа по трек-номеру  
✅ Отмена заказа

### 🚴 Тесты курьеров (Courier Tests)
#### Валидные сценарии:
✅ Создание нового курьера  
✅ Авторизация курьера  
✅ Удаление курьера  
✅ Попытка создания дубликата курьера

#### Невалидные сценарии:
✅ Создание без логина/пароля  
✅ Авторизация с неверными данными  
✅ Отсутствие обязательных полей  
✅ Работа с несуществующим пользователем

## 🧪 Технологии
- **Java 11** - основной язык
- **JUnit 4** - фреймворк для тестирования
- **RestAssured** - для HTTP запросов
- **Allure** - для отчётов
- **Maven** - сборка проекта
- **Faker** - генерация тестовых данных
